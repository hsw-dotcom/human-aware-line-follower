# 프로젝트 기능 흐름과 역사적 공백

## 실제 목적 (사용자 2026-10-31 추가 확인)

**지정된 적재 구간에 사람이 대기할 때만 정지**합니다. 해당 구간에 사람이 없으면 같은 색상을 감지하더라도 계속 주행합니다. 색상 센서는 사람을 검출할 구간을 식별하고 Raspberry Pi 카메라는 대기자를 검출합니다.

```text
기본 Arduino IR 라인 추종
        │
TCS34725 구간 표시 + 버튼 상태
        │
Arduino -> Pi: r:g:b:button (당시 문답에 남은 한 버전)
        │
작업 구간이면 before.jpg 촬영 -> count_objects.detect()
        │
  ┌─────┴─────────────┐
  │ 대기자 1명 이상   │ 대기자 0명
  ▼                   ▼
정지(0)             라인 추종(1)
  │
적재 완료 -> 버튼 입력 -> 재출발
  (잠시 색상 정지 구간 무시)
```

위의 0/1 의미와 단일 패킷 형식은 당시 남은 한 버전에 근거합니다. 다른 Arduino 개발 스케치는 반대 극성이나 다른 메시지 형식을 사용하므로 **실제 성공한 최종 Arduino–Pi 쌍은 미확인**입니다.

## 영상 지연 대응 경험

실제 장치 시험에서 사람 인식 정지에 성공했으며, 초기에는 영상 처리 지연으로 정지 위치를 지나쳤습니다. 검출 연산을 줄이고 **적재 정지 지점보다 앞선 곳에서 검출을 시작하도록 조정**했습니다. 정확한 촬영 시작 지점, 검출 완료 값 저장 방식, 정지 구간 인식 방식은 코드 원문 미확보로 재현되지 않았습니다.

## 복원 코드와 역사적 조건식의 차이

당시 문답에 남은 `색상 OR 사람` 정지식은 사용자 최종 목표와 불일치합니다. **실행용 복원은 색상 AND 사람**으로 수정했으며, 예전의 OR 식은 역사적 기록으로 그대로 보존했습니다. 정확한 2023년 최종 조건식은 확인되지 않았습니다.

현 복원은 카메라 영상에서 검출된 인원이 곧 적재 구간의 대기자라는 전제를 둡니다. 위치 판정 ROI/카메라 방향, RGB값의 환산과 실제 적재 지점까지의 이동 제어는 여전히 미확인입니다.
