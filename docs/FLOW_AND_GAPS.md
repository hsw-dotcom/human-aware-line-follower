# 최종 기능 흐름과 미확인 부분

## 사용자 직접 확인한 최종 역할

- **Raspberry Pi:** 주행 중 멀리 있는 사람을 반복 촬영·검출하고, 인원수는 자체 계산하여 **사람 존재 여부 0/1만 Arduino에 전송**합니다.
- **Arduino:** IR 센서 라인 추종, TCS34725 정지구간 판별, **해당 구간에서 사람 존재 신호가 있을 때만 정지** 및 적재 후 버튼 재출발을 담당합니다.
- Arduino는 **사람 수를 받거나 사람 수를 세지 않으며**, Pi는 **정지구간 색상을 판단하지 않습니다**.

```text
Raspberry Pi                         Arduino
주행 중 반복 프레임 추출               기존 IR 라인 추종
사람 수 계산 -> 이진 신호 0/1  --->   사람 존재 결과 유지
                                     TCS34725 정지구간 감지
                                     정지구간 + 사람 있음 -> 정지
                                     적재 완료 후 버튼 재출발
```

사용자 제공 초기 Arduino 스케치와 일치하도록 현재 복원에서는 `1=사람 있음`, `0=사람 없음`을 선택했지만 실제 최종 송신 극성은 확인되지 않았습니다.

## 기록상 불일치

- 초기 대화에는 Pi가 `r:g:b:button`을 수신해 `색 OR 사람`을 판정하는 제안이 있습니다. 이는 최종 실제 역할 분담과 **다른 개발 단계**입니다.
- Pi가 `people_num` 자체를 보내려던 11월 28일 코드는 **시험 기록**이며 사용자가 확인한 최종 설계가 아닙니다.
- 현 복원 Arduino의 RGB 역치(`r>=5`)와 재출발 무시 시간(2초)은 시험 코드를 참고한 **가정값**입니다.
- 사람 수를 언제 송신·유지했는지, 센서 감지 시점과 영상 검출 시간의 관계 및 카메라 ROI는 최종 원본이 없어 확정할 수 없습니다.
