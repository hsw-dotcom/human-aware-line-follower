# 최종 기능 흐름과 미확인 부분

## 사용자 직접 확인한 최종 역할

- **Raspberry Pi:** 주행 중 멀리 있는 사람을 반복 촬영·검출해 **0.3초 주기로 결과를 갱신**하고, 사람 수는 자체 계산하여 **0=없음/1=있음의 이진 신호만 Arduino에 전달**합니다.
- **Arduino:** IR 센서 라인 추종, TCS34725 정지구간 판별, **해당 구간에서 사람 존재 신호가 있을 때만 정지** 및 적재 후 버튼 재출발을 담당합니다.
- Arduino는 **사람 수를 받거나 사람 수를 세지 않으며**, Pi는 **정지구간 색상을 판단하지 않습니다**.

```text
Raspberry Pi                         Arduino
주행 중 반복 프레임 추출               기존 IR 라인 추종
사람 수 계산 -> 이진 신호 0/1  --->   사람 존재 결과 유지
                                     TCS34725 정지구간 감지
                                     정지구간 + 사람 있음 -> 정지
                                     적재 완료 후 버튼 재출발
```

`0=사람 없음, 1=사람 있음`이라는 신호 극성과 0.3초 갱신 주기는 **사용자 직접 확인**입니다. 정지구간은 색이 다른 라벨·테이프로 만들고 재질에 맞춰 조건을 조정했습니다. 사람이 있어 멈춘 뒤에는 버튼 전까지 정지를 유지하며, 재출발 후 잠시 **사람 신호와 색상 조건을 모두 정지 판단에 사용하지 않았습니다**.

## 기록상 불일치

- 초기 대화에는 Pi가 `r:g:b:button`을 수신해 `색 OR 사람`을 판정하는 제안이 있습니다. 이는 최종 실제 역할 분담과 **다른 개발 단계**입니다.
- Pi가 `people_num` 자체를 보내려던 11월 28일 코드는 **시험 기록**이며 사용자가 확인한 최종 설계가 아닙니다.
- 현 복원 Arduino의 RGB 역치(`r>=5`)와 재출발 무시 시간(2초)은 시험 코드를 참고한 **가정값**입니다.
- 인식 결과의 **갱신 간격 0.3초는 확정**이지만, Arduino에 실제 시리얼값을 매번 송신했는지/변화 시에만 보냈는지와 갱신 처리 지연은 최종 원본 미확보. 카메라 ROI도 미확인입니다.
