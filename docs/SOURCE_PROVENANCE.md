# 코드 출처와 확실성 수준

본 자료는 기존 프로젝트의 구두/대화 코드 설명을 근거로 만들어진 **재구성 예시**입니다. 실제 2023년 원본 파일은 현재 접근 가능한 프로젝트 자료에서 확인되지 않았습니다. 당시 사용한 코드가 확인된 것처럼 발표하거나 원본 저장소라고 표시하지 마세요.

## 대화에서 확인된 사항 (사용자 제공 설명)

| 기능 | 확인된 조건 |
|---|---|
| 역할 | Arduino 라인 추종 / Pi 사람 감지 / 시리얼 통신 |
| IR 신호 | HH→직진, LH→좌회전, HL→우회전, LL→정지 |
| 모터 제어 | LmotorCW=5, LmotorCCW=6, RmotorCW=9, RmotorCCW=10 |
| 버튼 | BUTTON_PIN 3, INPUT_PULLUP, 누름이면 button=1 |
| 센서 | TCS34725를 사용하여 RGB 색상 구분 |
| Arduino → Pi | `r:g:b:button` |
| Pi → Arduino | 정지=0, 진행=1 |
| 색 조건 | `r>=4 or r>=2*g or r>=2*b` |
| 최종 판단 | 버튼 우선 1; 색 구간 또는 사람 인식 시 0; 그 외 previous_result 유지 |
| 영상 처리 | 촬영해 `before.jpg`로 저장하고 `count_objects.detect()` 호출 |
| 지연 보정 | 목표 위치보다 앞선 색 구간에서 검출 시작 |
| 재출발 | 버튼 이후 1~3초 정지 신호 무시를 테스트하여 조정 |
| 실험 | 약 3~5m 사람 인식 사례 보고됨. 정량 성능/오류율은 불명 |

## 자연스러운 복원 가정 (사용 전 확인)

- IR의 물리 핀 번호 2/4 (확정 기록이 없음)
- 전원·모터 드라이버 극성·PWM 출력단, 속도 150/135
- TCS34725 채널 원시값을 합계 10으로 정규화, 센서 통합시간/증폭률
- 통신속도 9600, 개행 종료, 대기 800ms, USB 포트 `/dev/ttyACM0`
- 영상 640×480, 카메라 `RGB888`, 0.5초 재분석 간격
- 재출발 무시 기본 2초(당시 실제 최종 채택값은 불명)

## 엔지니어링 보완 (원본 코드라고 주장할 수 없음)

- 장시간 비전 추론으로 Arduino 통신이 멈추지 않도록 `VisionWorker` 사용
- 모터 제어 요청이 잘못되거나 빠지면 정지(fail-closed)
- 재출발 후 기존 추론 결과를 무효화해 과거 사람 검출이 되살아나지 않도록 처리
- 디바이스 없이 재현 가능한 시뮬레이터와 단위테스트
- `count_objects.detect()` 리턴형을 가정에 따라 단일 정수 또는 `(정수, 부가정보)`로 정규화

## 구성 자체가 대체인 부분

`raspberry_pi/line_tracer/count_objects.py`: OpenCV HOG 보행자 검출기는 **프로젝트에서 사용한 학습 모델과 무관한 대체 구현**입니다. 원본 TensorFlow 모델·파라미터가 발견되면 교체해야 하며, 당시의 3~5m 인식 성능을 재현했다고 주장할 수 없습니다.

## 의도적으로 제외한 것

Safe Watch(1번)와 졸음운전 감지 카메라(2번)의 소스, 모델, 웹 관련 내용은 혼합하지 않았습니다.
