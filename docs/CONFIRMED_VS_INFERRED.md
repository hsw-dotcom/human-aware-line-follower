# 2023년 라인트레이서 — 확정 사실과 복원 선택

| 항목 | 사용자/당시 코드로 확인 | 2026년 복원 선택·미확인 |
|---|---|---|
| **최종 역할** | **Pi는 사람 인식 및 0/1 존재 신호 변환, Arduino는 정지구간·주행·버튼 제어** | 최종 실행 파일의 정확한 소스는 미확보 |
| 사람 인식 | Safe Watch 사람 검출부만 추출해 재사용, Pi에서 먼 시야의 사람을 검출하고 **0.3초마다 인식 결과 갱신** | 실제 한 번의 추론이 0.3초 초과할 때 처리 방식·ROI·모델 파일 미확보 |
| 0/1 전송 | **0=사람 없음, 1=사람 있음**, Arduino에는 사람 수 자체를 전송하지 않음 | 실제 ASCII/종결문자·변화 시에만 송신 여부의 최종 원문 미확보 |
| Pi 송신 빈도 | 2023-11-24 대화에 결과 변경 시 송신 요구 | 복원은 최초 1회 + 변경 시. 최종 빈도 미확인 |
| 정지구간 | Arduino의 TCS34725가 감지, **라벨·테이프 색을 다르게 만들고 재질에 따라 색상 조건 변경**, 사람 신호와 AND 결합 | 개발 스케치 01의 `r>=5`는 복원 예시이며 실제 최종 역치 미확인 |
| 라인 추종 | IR HH=전진, LH=좌회전, HL=우회전, LL=정지 | 제공 스케치의 모터 극성을 선택 |
| 핀/속도 | PWM 5·6·9·10, IR 7·8, 버튼 D3, 시리얼 9600bps, 속도 255는 사용자 스케치에 등장 | 최종 채택값인지 별도 독립 확인 불가 |
| 재출발 | 적재 후 버튼을 누르기 전까지 정지 유지, 버튼으로 재출발하고 일정 시간 **사람 신호·색상 정지구간 모두 무시** | 복원에서 2000ms 선택, 최종 시간 미확인. 카메라 추론 자체를 중단했는지는 미확인 |
| 카메라 코드 | `netifaces` `wlan0`, `get_frame(ip)` MJPEG `stream.mjpg`에서 프레임 추출 → 검출 | `/home/pi/project/image/before.jpg` 경로는 검출기와 일치시키기 위한 선택 |
| AI 모델 | TFLite 사람 클래스 0, 640×640, 신뢰도 0.2 이상(Safe Watch 원본) | 당시 라인트레이서 추출 파일 원문·가중치 미확보 |
| 실기기 | 사람 인식과 정지구간을 함께 이용해 정지 시험 성공; 지연 때문에 검출 시작 시점 선행 | 성공률·시간·거리 측정 로그 미확보 |
| 역사적 대안 | Pi가 RGB·버튼으로 `색 OR 사람` 판단, 사람 수 직접 전송하는 별도 시험도 대화에 존재 | **최종 역할이 아니라 개발 기록**으로만 보존 |

이전 현대식 `VisionWorker`, `Coordinator`, HOG 대체 감지, 임의의 통신 fail-safe 등은 2023년 구현 근거가 부족해 포함하지 않았습니다. 현 코드도 2023년 전체 실사용 파일과 동일함이 입증된 것은 아닙니다.
