# 원본 미확보

이 디렉터리에는 복구된 2023년 원본 소스가 없습니다. 원본 `.ino`, 원본 Raspberry Pi Python 파일, 학습 모델, 실제 배선 자료 등은 현재 확보하지 못했습니다.

`arduino/` 및 `raspberry_pi/`의 코드는 과거 대화 규칙을 반영해 보완한 복원/참고 코드입니다. 실제 원본이 확인되면 날짜와 해시, 출처를 기록해 별도로 보존하세요.

추가 확인: Safe Watch의 **사람 검출 기능 원본**은 다른 저장소의 `src/python/count_objects.py`에 남아 있습니다. 이는 라인트레이서에 추출한 당시 파일 그 자체는 아니지만, 라인트레이서 검출부의 코드 유래를 설명하는 직접 근거입니다. `docs/SAFEBWATCH_REUSE.md` 참고.
